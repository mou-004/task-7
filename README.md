# 🛍️ Interactive E-commerce Product Page

A responsive product page for **SonicPro X1 Wireless Headphones** built with HTML, CSS, and JavaScript.

### Features

* Product image, price & discount
* Black, White & Blue color selection
* Quantity and dynamic total price
* Add to Cart confirmation
* Buy Now button
* Customer reviews
* FAQ section
* Responsive design

### Technologies

* HTML5
* CSS3
* JavaScript

### Run

Open `index.html` in any web browser.
